# Documentation

User-facing validator tutorials are distributed as static PDF guides rather
than executable Jupyter notebooks. This keeps installation independent of
Jupyter and avoids requiring users to download the multi-gigabyte simulation
datasets used for scientific validation.

The PDF guides should combine a concise public-API tutorial with recorded
validation results generated by the maintainer workflow in `validation/`.
They should state the tested dataset and parameters, show recovered
coefficients and fit metrics, and include enough code to demonstrate normal
package use without requiring the reader to rerun the large validation case.

The PDFs will be added after the current validation cases are rerun and their
results are checked.
