# Examples, tutorials, and validation fixtures

This directory contains small processed simulation fixtures used to exercise
the validator across different solvers.

The `tutorials/` directory contains the user-facing introduction notebooks.

- `data/ans/`: processed ANS fields
- `data/ludwig_checkpoint_dense/`: processed Ludwig fields
- `tutorials/q_validator_3d_introduction.ipynb`: full 3D Q-validator tutorial
- `tutorials/velocity_validator_3d_introduction.ipynb`: full 3D velocity-validator tutorial

Examples should import the installed `activebe_validator` package directly.
